# BLOCKED register

One row per blocked item: what it is, which milestone it blocks, why it is
blocked today, the exact steps that unblock it, and how the unblock will be
verified. A blocked item is reported as **BLOCKED — not pass, not fail**: a
milestone that cannot exercise a capability must say so, and must not present
the missing coverage as green (ADR-0037 "blocked ≠ pass").

Update a row in place when the unblock happens; move the row to "Cleared" at
the bottom with the date and the verification evidence, rather than deleting
it.
